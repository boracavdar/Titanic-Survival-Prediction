## 🚀 Project Overview
This repository contains an end-to-end Machine Learning classification pipeline designed to predict the survival probabilities of passengers aboard the Titanic. Using historical demographic and ticket data, the project showcases the foundational and advanced techniques required in modern Data Science workflows.

## 📊 Data Pipeline & Architecture
1. **Exploratory Data Analysis (EDA):** 
   - Conducted deep statistical analysis to uncover correlations between passenger class, gender, age, and survival rates.
   - Utilized dynamic data visualization to identify underlying patterns.
2. **Data Preprocessing & Cleaning:**
   - Executed strategic missing value imputation (e.g., handling missing Age and Cabin data).
   - Eliminated outliers and normalized data distributions.
3. **Advanced Feature Engineering:**
   - Created new predictive features from raw text data (e.g., extracting Titles from Names) and combined features (e.g., Family Size) to boost model accuracy.
4. **Predictive Modeling:**
   - Built, trained, and evaluated multiple classification algorithms including Logistic Regression, Random Forest, and Decision Trees.
   - Conducted rigorous Hyperparameter Tuning to prevent overfitting and maximize generalizability.

## 📈 Evaluation Metrics
The final optimized classification model was evaluated using robust statistical metrics rather than just baseline accuracy:
- **Accuracy & Precision**
- **Recall (Sensitivity)**
- **F1-Score**
- **Confusion Matrix Analysis**
